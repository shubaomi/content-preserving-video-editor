# 产品片声画分镜卡

在创意 brief 阶段选卡，不按时间间隔轮换。先写“给谁看；看完能说清哪一个变化；哪段授权素材证明它”。只有一句产品描述时可以写分镜，不能把它当实测。已有录音的项目以原话和 EDL 为准；下列口播例子仅供**新写且获授权的解说**参考，不是替换原话的台词。

### A · 从产品意象进入真实操作

- **适合**：物件与功能有具体联系，如纸页与阅读清单。找不到共同形状或动作时，直接切入产品。
- **三格分镜**：纸角近景，侧光照出厚度和接触阴影 → 页边掠过时，同位置、同方向接成列表分隔线 → 镜头稳住，用户看到实际的筛选结果。光影和景深只用于纸面，不模糊证据。先画三个关键姿态，看得通再做中间运动。
- **声音**：交谈口吻提出需求，例如“我只想看还没读的那几本”；纸张轻响从抬起到落下，落点后让位给结果。不要让配音、翻页声和音乐重拍同时抢这一下。静态意象不能假装是产品操作。

### B · 一次操作，一个可见结果

- **适合**：筛选、导出、比较、设置变更。素材要有可信的起始状态、操作和结果；只拿到两张状态图就做标明的前后对照，不编造鼠标路径或响应速度。
- **三格分镜**：保留操作前的上下文 → 对准真实控件，视线与鼠标一起到达 → 同一取景留住结果供阅读。界面缩放、滚动或换状态后重新绑定目标，不能沿用旧坐标。
- **声音**：专业工具用同事演示的语气，操作本身明显就让旁白说收益而不是念按钮名。真实落点可用轻点击，原声已有就不叠；没有操作证据就不用点击声暗示执行。抽象数据看板不必硬配电影式冲击音。

### C · 让实物的材质和动作自己说话

- **适合**：吸附、折叠、扣合等看得见的动作。用授权实拍证明功能；生成式氛围镜头只作示意，不证明手感、力度或耐久性。
- **三格分镜**：交代手和部件的位置 → 近看接触、形变或遮挡变化 → 稳住看最终状态和尺寸关系。找不到接触点就退回清楚的实拍中景，不用粒子掩饰。
- **声音**：旁白像递给朋友看一样，在接触处留一口气。优先保留实录材质声；需要拟音时用有权使用的素材并记录来源，不能用拟音暗示实际上没有的锁定、强度或性能。

### D · 安静的前后对照

- **适合**：文字密集、结果细微或操作声会分散注意。对照要保持相同条件，改变的部分清楚可指；不同条件不得暗示性能对比。
- **三格分镜**：先看变化前 → 用相同裁切直切变化后 → 停留到能读出差别。原片已经清楚时直接用原片，不强行做转场。
- **声音**：把重音放在真正变化的词，解释一件画面本身没说透的事；其余留白。需要有声宣传片时，这一拍可静，不代表整片用字幕代替解说。

### 把一张卡变成本片分镜

先定“谁在什么情境下对谁说”，再定配乐。例如：效率工具是同事带你完成一次任务，语速利落，节奏脉冲可跟操作但在读数时退下；故事型产品是创作者请你靠近看，声音可亲近、句间有呼吸，把一次翻动交给环境声；实物体验则让观众先听见接触的一瞬，再听解释。这些是候选方向，不是品类绑定。先用干声试配关键镜头，再试听加音效、加音乐的版本；没有合适的授权音乐，宁可保留干净的人声和现场声。

在现有创意笔记或 HyperFrames 的 `frame.md` 填下面一行；它不是额外的 JSON 合同，也不是给已冻结的 Storyboard 添加字段：

| 观众的问题／真实证据（事件、素材或目标） | 选卡或直切的理由 | 起势 → 切点锚点 → 可读结果 | 原话或获授权新旁白／重音与停顿 | 声音落点或留白／来源 | 缺证或效果不佳怎么退 |
|---|---|---|---|---|---|
| … | … | … | … | … | … |

正式执行时只使用当前合同允许的结构、素材和音频决定；不兼容的创意只留候选，不让渲染器改写获批方案。录制类型、产品气质与目标受众优先于模板：同一个“筛选”动作，工具教学可直接用 B，品牌短片可由 A 接 B，用户只要操作证明则跳过整套创意卡。
