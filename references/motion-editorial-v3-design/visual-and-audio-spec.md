# 两类视觉与声音规范

方向批准不等于已经见过并批准具体构图、运动和音效。本规范定义首轮候选，实际短片仍待用户审美决定。不得用技术分数替代“是否廉价/是否自然”。

## 共用原则

观众应先看懂真实动作/变化，再得到图形帮助。顺序是内容任务→主焦点→镜头处理→必要图形→声音，不能从组件库倒选一句话塞进去。

每个事件明确 viewer_task、信息增益、主焦点、选择/拒绝理由。没有增益就 source/quiet/caption-only。字幕负责原话；大标题/图形只补充层次、关系或定位，不重复整个字幕。禁用自动圆环、光束、玻璃卡、粒子、无信息边轨、无依据箭头和全程漂浮装饰。

保留字幕 semantic_emphasis：每屏至多两个来源匹配强调词，放大仍受原合同 105–120% 限制；先语义分屏再样式。正文字幕继续原词原时序，不能为钩子另造一句刺激性台词。不在本轮引入逐字蹦跳字幕。

首轮只使用当前已授权本地字体和现有资产。默认检查 Microsoft YaHei UI 实际安装/字重文件，缺失需显式替代和重截图，不静默依赖浏览器 fallback。文字不靠外发光塑造质感，忙背景可用局部实色衬底，不用低对比玻璃。

保留现有更严格的保护区/对比度/平台安全规则。产品/字幕/关键 UI 硬保护；人脸/手的受控软遮挡仍只能来自既有精确语义窗口批准。本轮没有扩大允许遮挡范围。

## A. 真人产品编辑感

### 构图与样式

- 主体：真实产品动作，人物作为可信讲解者，不能把人像变成装饰背景。
- 工作色：深墨 `#1B2528`、暖白 `#F5F3EE`、沿用品牌薄荷 `#51E3C2` 作单一强调；不默认混用霓虹双色渐变。仅解释性图形使用这组色，原片肤色不做自动风格 LUT。
- 字重：字幕既有清晰底样；解释关键词 600–700，大小约该布局字幕的 1.2–1.5 倍，受可读和安全区约束。每次突出一个短词组，不做多栏大字压住实物。
- 景别变化来自真实帧和实际分辨率，默认不扩大超过像素/清晰度实测容许值；无清楚细节时保留中景，不生成产品外观或假的充电指示灯。
- 解释文字靠近真实动作但不盖住焦点；“靠近”必须由当前产品/手/字幕区域计算，不能固定贴脸边。

### 首批结构（不是样式皮肤）

| Recipe | 适用语义 | 结构与动作 | 声音 | 回退 |
| --- | --- | --- | --- | --- |
| A01 action-detail | 一次可见实物操作 | 原中景→受控真实细节取景→结果停留→回到原构图；同一视频画面不伪造第二机位 | 原声为主；没有可用动作声则静默 | 原画＋简短字幕强调 |
| A02 anchored-reveal | 动作完成后解释结果 | 一处局部短标签随结果揭示；跟随有证据的产品空间；不加装饰圆环 | 可选一枚低存在感授权 cue，不必每次有 | 没跟踪证据则 target-free 字幕强调 |
| A03 compare-in-context | 源片有真实前后状态 | 两个真实状态在同一明确边界下比较，标明先后；不改变测量/因果 | 比较落点可静默，语音不断 | 顺序原画，不伪造同时存在 |

### 10–15 秒首轮意图板

从“磁吸工艺说明→放入动作→可见结果”附近找到完整语义窗口，实际 in/out 在读取词与相邻画面后记录，不凭此表写死。

1. 准备：正常中景、自然字幕，让产品位置可辨。
2. 动作：轻微取景调整把注意力交给耳机盒，文字让位；不遮住吸合瞬间。
3. 结果：画面确有对应状态才出现简短解释；没有可见充电证据，只表达原话/操作，不替产品测试背书。
4. 回落：干净退场，回到人物和下一句，不留无意义的线。

这段只验证 A01/A02 的视觉节奏，不强制把 A03 塞进去凑种类。

## B. 专业软件演示

### 构图与样式

- 原界面是主角。首先解决阅读位置与操作因果，不给原 UI 外面再套一层模拟 SaaS 仪表盘。
- 工作色：深墨 `#172033`、白 `#FFFFFF`、蓝 `#2B6CAD` 单一强调；第三方不沿用 HongRun IP 人像、名字、个人片头片尾或第一人称背书。
- 标注是局部文字、状态下划线/轻遮罩、必要的路径，而非默认大圆角徽章。短标签不覆盖真实导航/结果，远离字幕。
- 原片低清：布局以局部放大窗口和上下文定位权衡，先实测可读；原图不能读清的数字不得 OCR 猜写成“高清重绘”。
- 焦点只在 UI 已出现的有效窗口激活。滚动、弹窗、路由切换时停止旧标注，重新定位或退回原画。

### 首批结构

| Recipe | 适用语义 | 结构与动作 | 声音 | 回退 |
| --- | --- | --- | --- | --- |
| B01 locate-act-result | 真实一次操作→结果 | 先建立全局定位，局部聚焦动作，结果出现时移交注意力，最后回到上下文 | 不每次点击配音；必要时一枚低存在感 cue | 原画＋字幕 |
| B02 progressive-proof | 多个真实数据类型/步骤 | 保留同一容器和视觉层级，只更新当前步骤/对应 UI；不每项重新弹卡 | 稀疏 cue 或静默 | 按原片顺序说明 |
| B03 state-comparison | 原片能证明前后差异 | 两个明确时间点的真实界面并列/擦除比较，注明状态，保证数字来源 | 原声主导 | 原画顺序，禁用虚构对照 |

### 10–15 秒首轮意图板

从现有 BI 原片选择完整“入口或操作→界面响应”的窗口；数据数量的口头介绍若没有实际状态变化，不强充作功能演示。

1. 定位：画面让观众知道正在看哪个区域，不额外套外框。
2. 动作：短而清楚的聚焦变化，不抢走真实鼠标和关键内容。
3. 响应：等待原界面真正变化，再揭示结果解释。
4. 退出：恢复原界面阅读，目标丢失立即退出。

## 动作参数与声音边界

原型起点：入场 180–320 ms、注意力移交 240–480 ms、退出 120–220 ms；使用连续平滑且可 seek 的曲线，不默认弹簧过冲。不机械套全事件同一速度，原话落点和真实动作优先；这些是可调设计区间，不是“越短越高级”的评分。

持有时间按信息可读性和动作窗口决定；原语义/目标窗口不足以完成动作时，简化动作而非延长出界。关键文字/动作落点沿用现有更严格词/手势同步阈值。每个非静默事件记录 cue 或 intentionally_silent 及理由。

不强制复用旧 PBM-S 家族配额；新路线使用现有音频 owner 与权利/混音测量，但 sonic choice 独立提出。不能以“音效多样”硬给每个动效配声。未授权新声音不调用生成/下载工具。全样片响度建议沿现有 -16 LUFS 目标及交付真峰值≤-1 dBTP，参数以正式音频合同为准。机器测量之外需要完整听审。

本轮使用直切/构图连续变化。高级 shader、镜头炫转、景深伪造、产品 3D 替换均不在本轮。后续有具体价值再冻结对应运行时与回退。
