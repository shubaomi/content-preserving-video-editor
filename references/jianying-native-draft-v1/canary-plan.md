# Short real-project canary

## Source and cost boundary

Use one already authorized 45–60 second HongRun portrait product sample with
current upstream analysis, EDL, semantic brief, captions, NLE package and layer
evidence. Do not render a long/full video. Reuse current layer derivatives; only
missing canary-specific draft metadata may be generated after implementation is
approved.

## Sequence

1. `fixture`: create a 10–15 second synthetic isolated draft package without
   touching the Jianying store; validate schema, security and round-trip.
2. `real_short_build`: build `repair_draft` and, if all assets are current,
   `layered_reconstruction` under the project-local published root.
3. `install_proposal`: show exact target, editor version, adapter version,
   package size and rollback boundary. Wait for one explicit install approval.
4. `jianying_open`: user manually opens the newly installed draft. Automation
   may not click, export or claim success.
5. `five_edits`: user performs the required tasks below.
6. `returned_short`: export manually and run existing full returned-file QA.
7. `decision`: HongRun records usability, fidelity, preferred profile and
   willingness to reuse for this exact editor/adapter tuple.

## Five edit tasks

1. Correct one subtitle, split/merge its sentence, and change one emphasis span.
2. Move, trim or hide one event motion overlay without affecting base video.
3. Mute one event SFX while preserving dialogue and BGM.
4. Move/remove one IP or product-support image.
5. Change outro CTA copy and hide one icon or outro SFX.

## Observations

Record import/open result, missing media, relink count, font/style fidelity,
alpha behavior, layer alignment, audio alignment, time to complete each edit,
app warnings, crash/recovery, and returned-export hashes. Screenshots are review
evidence only when tied to exact draft/build/editor versions.

## Pass boundary

All five tasks must be possible without rebuilding the full HyperFrames project;
the reference and returned edit must remain semantically correct; no existing
draft may change; and HongRun must explicitly judge the workflow useful. A pass
applies only to the exact OS/editor/adapter/profile tuple and does not authorize
production-default.
