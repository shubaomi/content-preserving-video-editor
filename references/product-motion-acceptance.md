# 产品介绍样片：动效、声音与转场验收

适用于有原片的产品介绍、从经授权的真实界面开始制作的介绍样片，以及对已有空间转场的局部返修。它是制作和审片规则，不是新增的自动渲染器。沿用当前路线的样片范围、[技术与人工审核门](quality-gates.md)和导出授权。

## 先判断用户要看什么

| 要回答的问题 | 应交付什么 |
|---|---|
| “这个操作真的有效吗？” | 真实起始状态 → 操作 → 可见结果。允许明确标注为无声的操作验证；说明字幕不是口播。没有操作过程的截图只证明状态，不当作连续实录或速度证据。 |
| “观众能看懂产品、愿意继续看吗？” | 用一句话写出观众应理解的价值，再以真实镜头或界面证明它。明确要求解说、音效或有声时，交付能播放对应声音的创意样片；操作验证只是其中的素材。 |
| “这个转场不自然，能改好吗？” | 锁定上一版和问题时间窗，先看动作从哪里开始、在哪里落稳，再改对应的镜头或声音。保留上一版供同段对比，不借机重做其余段落。 |

已明确的偏好直接沿用；只有“无声操作验证”与“有声宣传样片”的选择会改变交付且无法判断时，才补问一次。只有文案而无可核实素材，可以先做分镜或标为示意，不伪造功能、操作或效果。

## 制作与验收：看哪里，怎样判

| 检查项 | 通过条件与复核方法 |
|---|---|
| 真实内容与可读性 | 对照原素材看关键时刻：观众看得见要操作的对象、发生的变化和最终结果。必要时镜头和装饰停下来，让结果读得清。插画、隐喻和重建的场景不冒充真实界面、实物或使用经历；不用遮罩、景深或特效替代缺少的产品证据。 |
| 动效选择与节奏 | 每个重点动作对应一个目的，如引导视线到按钮、揭示变化或衔接两段叙事。按产品气质决定用平面、真实空间还是安静直切，不以粒子数、转场数量或某种引擎判优。想要“奇幻”时，装饰可以承接情绪，但进入操作窗口后仍应一眼看清重点。 |
| 空间与连续性（选用时） | 正常速度看视线是否从前一主体自然落到下一主体；慢放或逐帧看起势、中段、落点和稳定后的画面。转轴、接触点及前后遮挡关系可信，加减速有来由；不应有非预期的匀速骤停、跳位、穿模、闪面，或靠遮罩提前盖掉未完成的落点。若有返程，两向都要看。 |
| 翻书示例（仅当选择翻页） | 用书脊和纸角作参照：书脊相对书体稳定，纸角先起、纸面随之卷过书脊、落在正确的一侧，再贴合静止页。检查页背、邻页、书中立体物是否错误穿透，前后内容是否接得上。镜头可以移动，但不能把书脊漂移或整片硬转误当纸张弯曲。 |
| 解说与声音 | 在交付的播放器里实际听：关键句能听清，音效落在有意义的动作上，音乐如选用应给说话让位；静音要有理由，不逐字配点击声。保留可修改的旁白、音效和音乐来源或分轨，说明授权；不克隆未授权声音。缺少可用解说就标待补，不把无声稿当完成。 |
| 播放与导出 | 在正常速度从转场前播过落稳点，并从中途回看同一段，查声画同步和状态能否复现。浏览器能播放只证明预览。若交付 MP4，还要检查导出文件的时长和所需音视频轨、解码错误，并对成品复听关键句和音效、按现有音频门检查响度与峰值；有音轨不等于听得见解说。 |

## 返修留下哪些证据

### 产品片分镜的三次回看

针对从[声画分镜卡](../assets/product-promo/shot-and-voice-cards.md)发展出来的镜头，在现有审片记录中检查：

- **静音看结果。** 以目标设备的正常观看尺寸看一遍，写下实际看清的动作和变化。检查最深推近处的原生裁切像素与输出占用像素；字边已糊就按相同布局高密度重采，不能重采就收小推近或换景别。放大导出尺寸、让模型重画界面文字都不是修复。
- **只听人声，再听混音。** 旁白有没有说清对观众有用的结果？重音是否落在观众已经看得到的对象上，而不是提前剧透一个未出现的按钮？检查音乐、撞击和拟音有没有盖住辅音、尾音。需要个人声音时，读错专名与“读对了但不像本人”分别记录；后者用授权原声对照连读、轻重和句尾，只返修受影响的整短句。不要逐字拼接、拿 ASR 正确率判相似，或因参考音色接近而克隆别人的声音。
- **合起来看切点。** 在转场前、中、落稳后三个位置看同一视觉锚点，再按原速播放确认视线接得上、结果留得够久。视觉 A/B 固定已认可的人声与混音；声音 A/B 固定画面并匹配试听响度。声音相似度、产品气质和审美是否合适，仍由用户判断。

### 审看记录

- 在本地审看记录中写明：对应诉求、版本、镜头与真实时间窗、预期效果、正常速度片段或回放定位、关键相位帧、技术结果和待用户判断项。不适用的检查写明理由；未试听、未导出或缺证就写待核验，不写通过。
- 用相同时间点、画幅和播放速度对比前后版，至少保留能暴露原问题的动作过程和落稳画面。对承诺不改的界面、字幕时序或混音，按对象比对素材哈希、时间轴或同时间点的解码画面；素材未变不能代替检查实际合成。只重验受影响的部分及其衔接。
- 技术检查回答“是否穿模、同步、可读、可听”，审美留给用户判断“是否自然、合适、值得保留”。“比上一版好”只记录为对这一版的反馈，不自动成为品牌默认、成片批准或发布许可。仅把通用规则入库；审看素材和项目收据留在项目本地。
