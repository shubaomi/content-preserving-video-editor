# 参考视频与个人 IP 编辑指引

本指引用于已有录制素材的内容判断、参考分析与创意微调。它在现有
video-use / semantic brief / HyperFrames / publishing / feedback 合同内工作，
不新增运行时阶段，不把人工编辑建议伪装成机器门禁结果。

## 先明确素材角色

- **保留的源视频**：原话、人物、时间轴是事实来源，按 preservation 规则剪辑。
- **风格参考**：学习开场、叙事、画面层级、动作与语句的关系；时间码只描述参考本身。
- **授权素材**：B-roll、插图、声音可按用途加入，保留来源及授权记录。
- **生成式改编**：更换人物、声音、台词或情节是一项单独任务，不能从“参考这个效果”推断授权。

一句“克隆视频”有歧义时，先复用用户已说明的改变项。只对仍会实质影响
人物、原话、成本或输出的部分提问。Hypit 的生成优先习惯不得覆盖本 Skill
的内容保留边界；当前 Director 没有自动 Hypit 执行通道。

## 用现有证据完成编辑判断

在已有分析和逐词转录可用后，向用户简要说明：本期受众、核心问题、
一句话主张、可见证据、预期收获、适合的栏目与一个主要行动。
明确区分用户确认、素材可证实、编辑推断和未知，不编造 HongRun 的经历、
专业资质、产品效果或受众定位。已有 profile 只按其真实字段使用。

给出继续剪辑、建议补录、建议拆分或建议暂缓的理由。它是建议，不凭一个
评分自动拒绝用户要求的剪辑，也不授权改写 EDL。拆分或开场重排仍走原有批准。
普通视频可以用一段项目笔记完成，不强制填写新 JSON，不要求新增账号档案。

## 分析参考的有效机制

观看参考的完整论述，再对关键变化做连续帧和声音检查。记录：

| 记录 | 应包含的内容 |
| --- | --- |
| 观察 | 时间范围、实际画面/台词、图层进入/持有/变化/退出、来源证据 |
| 解释 | 这一变化解决什么理解或情绪问题；明确标为编辑推断 |
| 迁移 | 本片对应的真实词、动作或章节；没有对应点则不采用 |
| 改写边界 | 哪些结构可借鉴，哪些人物、音乐、素材、标识不可照搬 |

为同一机制复用一次分析，不为每个重复动作重复生成研究。静态截图能证明
构图，不能单独证明运动、音效同步或节奏。未观看的内容不得写成已观察事实。
不把对方的“爆款”“100M views”等宣传当效果证据。

## 让观点、证据和情绪共同决定动效

观点需要清晰关键词；演示需要观众看见实物/界面的真实变化；个人经历需要
表情、声音和恰当留白。先判断该段的任务，再选择现有 recipe 或记录不可用。
完整原画、安静段落或字幕强调都可以是最佳选择，不能用数量配额填动效。

把重要揭示绑定到现有 word ID、semantic event ID 或观察到的动作，按 EDL
映射到输出时间。参考的第 3 秒不是本片第 3 秒。音频、剪辑或速度变化后重新
检查时间映射；仅改颜色时复用转录、EDL 和未受影响的素材。现有 state 若会
失效整个下游阶段，按实际行为报告，不承诺尚未实现的事件级局部重建。

动效里展示的数字、结论和对照需指向实际证据。生成式画面可以说明概念，
不能充当产品测试、界面已成功执行或客户结果的证据。

## 字幕：先分意思，再处理行宽，最后做强调

审查相邻两屏，而非只看单屏是否溢出。重点检查修饰语与中心词、否定词、
数量与单位、产品名、句末补语，以及“同时/接下来”等新句开头。

例如原话“采用了磁吸的工艺制作的，轻轻一放……”中，“的工艺制作的”
属于前面的工艺描述，不应为凑长度与“轻轻一放”合屏。长句可以在合理的
从句边界分屏；不能要求所有完整长句都挤进一行。以语义完整的短语单行呈现
为优先，必要的双行应可读且不混入下一句。避免压小字号来掩盖分组错误。

保留逐词文字与时间，按现有字幕桥接和修正账本修改分组或有证据的错词。
ASR 的标点只是证据之一；听实际音频并结合上下文复核。无法确定的术语
标记待核对，不猜。不要采用其他系统允许任意 display/speech 双文本的规则
来改写当前内容保留字幕。

SRT 管文字与分屏，ASS 管样式，HyperFrames 管独立动效；原话字幕与解释性
标题分别处理。风格修改不能改变字幕词序或时间。保留可编辑交接包，并说明
烧录 MP4 中的文字无法直接恢复成可编辑字幕。

## 包装与复盘

标题、封面、开场、CTA 使用现有 editorial promise/proof closure；每一项
承诺都能在本片找到兑现。可以提出不同包装候选，避免重渲染多个相同母版。
一条视频只选一个主要 CTA，按解释、收藏、下一期、交流或咨询的实际目的确定。
不默认给第三方录制视频加 HongRun 第一人称表达。

已有栏目和品牌资产可复用；新定位、固定栏目名和个人主张保留候选状态，
不因一次剪辑就写入共享 profile。日常内容少做可选实验；重点内容可增加
开场对照和风格样片，但保留相同的内容、字幕、权利和人工审美门。

发布后使用现有 `post_publish_metrics.py` / `feedback_loop.py` 接受用户导出。
播放少、观察时间不同、流量来源不同会影响解释。低完播只能产生检查开场和
节奏的假设，不能证明原因；同一发布的多次快照只是一条视频。评论可人工归纳
为追问、异议、购买意图和下期候选，删除身份信息，不自动抓取或联系评论者。
跨视频学习和自动映射的新合同见待批准的 `ip-content-loop-v1/`。
