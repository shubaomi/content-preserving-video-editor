# Style Reel Plan

Status: planned only; no media render is authorized in this phase.

## 1. Objective

Use one controlled 30–45 second comparison to decide the HongRun portrait brand
direction before modifying production defaults or rendering a full video. The
comparison isolates expression language: source, EDL, words, captions, semantic
meaning, event set, duration, output dimensions, and review mix policy are
identical.

The existing `告别2025` portrait canary is the proposed first source because it
already has authorized source evidence, word/EDL/caption artifacts, three
approved semantic render events, quiet decisions, and a documented brand-taste
rejection. This document does not authorize re-rendering it.

## 2. Validation edit

The implementation should create an isolated Style Reel EDL of approximately
34–42 seconds that preserves source order and includes:

- `impermanence` — concise mark/emotional realization;
- `life-halves-question` — genuine two-concept relation;
- `recover-happiness` — emotional resolution;
- at least one quiet source passage to test restraint.

The exact in/out windows must be recomputed from current video-use word and EDL
evidence and shown to the user before the first Style Reel render. The isolated
validation EDL never replaces the video's approved preservation EDL or automatic
master.

## 3. Common comparison basis

All directions must share:

- exact source and source hash;
- exact validation EDL and segment order;
- exact output-timeline transcript and captions;
- exact semantic opportunity set and approved visible copy;
- exact protected region and subject/face/hand evidence;
- exact canvas, frame rate, codec review preset, and duration;
- exact voice track and SFX/BGM comparison policy;
- identical review timestamps and contact-sheet phases.

If any common input differs, the entire comparison is stale.

## 4. Direction A — Luminous Intelligence (recommended)

Character: light-future cinematic, intelligent, energetic, controlled.

- Primary recipes: PBM-01, PBM-02, PBM-04, PBM-08.
- Optional macro when the validation EDL contains a verified boundary: PBM-07.
- Visual signature: mint/cyan orbit and focus beam, variable-weight type,
  shallow depth, gentle camera release, warm resolution.
- Rhythm: calm base, short decisive bursts; normally one attention-heavy layer.
- Sonic signature: PBM-S01, PBM-S03, PBM-S05.
- Distinguishing hierarchy: person -> meaning phrase -> luminous relation ->
  ambient depth.

This is the recommended starting direction because it is more expressive than
the current cards while matching the user's earlier preference for lively,
light, cinematic visuals.

## 5. Direction B — High-Energy Creator

Character: confident knowledge creator, faster and bolder without sticker
collage or gaming UI.

- Primary recipes: PBM-01, PBM-03 when gesture evidence exists, PBM-05, PBM-07.
- Visual signature: larger variable-weight changes, faster masked entries,
  controlled punch camera, stronger cyan/amber contrast, short icon/path bursts.
- Rhythm: more micro beats inside the same semantic event; quicker settle and
  longer quiet reset between events.
- Sonic signature: PBM-S01, PBM-S02, PBM-S04.
- Distinguishing hierarchy: person/gesture -> kinetic phrase -> camera energy ->
  supporting trace.

It must not introduce more semantic events than A/C. Its apparent richness comes
from choreography inside the same approved events.

## 6. Direction C — Humanist Cinema

Character: reflective, warm, cinematic, emotionally restrained.

- Primary recipes: PBM-02, PBM-05, PBM-06 only with relevant assets, PBM-08.
- Visual signature: slower focus changes, warm light, subtle texture, quiet
  spatial type, semantic cutaway only when it deepens meaning.
- Rhythm: fewer sharp micro accents, longer but visibly evolving meso phrases,
  deliberate silence.
- Sonic signature: PBM-S02, PBM-S05; more intentionally-silent decisions.
- Distinguishing hierarchy: person/emotion -> light/depth -> phrase -> evidence.

## 7. Required structural distinctness

The three directions must differ in all five dimensions:

1. DOM/component hierarchy;
2. spatial layout and person relationship;
3. camera/composite intent;
4. phase choreography and energy curve;
5. sonic family/decision pattern.

Changing color, font, easing, or entrance direction alone fails the comparison.
Normalized fingerprints are reported, but actual full-frame playback and phase
contact sheets remain required.

## 8. Review package

One `portrait-style-review.html` should embed:

- source/baseline plus A/B/C synchronized playback;
- scrub-lock and common event markers;
- original sentence, approved phrase, viewer takeaway, energy decision, recipe,
  and rationale for each event;
- entrance/mid/pre-exit/post-exit contact sheets;
- voice/SFX-off, SFX-on, and optional BGM-off/on toggles;
- automatic gate results and any multimodal rejection/recommendation;
- exact user-only questions from `brand-aesthetic-spec.md`;
- pending correction proposals only—no direct artifact mutation.

Desktop review is required; mobile review verifies usability and thumbnail/read
behavior but is not the sole brand-approval surface.

## 9. Decision outcomes

- `select`: all user criteria are yes and one direction is chosen; create a
  provisional Golden request.
- `revise`: retain exact feedback and affected attributes/events; rerender only
  affected reels after approved corrections.
- `reject_all`: keep portrait v2 disabled and return to design; do not select the
  highest automatic score.

Any changed reel, contract, caption, audio, or evidence invalidates the decision.

## 10. Second-topic promotion

After the first Style Reel direction is approved, validate the same profile and
implementation on a different HongRun portrait topic, preferably a brighter and
more gesture-rich knowledge/explanatory clip. It may use content-appropriate
recipes but must retain the same signature primitives, typography, palette
family, motion character, and sonic identity. Production default requires both
named-user approvals.
