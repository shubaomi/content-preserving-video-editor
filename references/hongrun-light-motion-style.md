# HongRun Light Motion Style

The approved visual identity for dynamic tutorial and talking-head overlays is
light, calm, and precise: deep ink `#15382d`, mint `#35c99a`, warm signal
`#ef9343`, paper `#f7fbf8`, and soft line `#dcebe4`. Use Microsoft YaHei for
Chinese readability and a monospace accent only for short UI labels. Motion is
playful in short accents, never noisy: light spring for a pop, `expo.out` for
an annotation draw, `power3.out` for an explanation, and `sine.inOut` for a
micro camera shift.

Do not use full-canvas topic images during explanation, duplicate an existing
caption sentence, obscure a face/cursor/control, or reuse one entrance pattern
as the default. Keep the original frame as the dominant visual.
