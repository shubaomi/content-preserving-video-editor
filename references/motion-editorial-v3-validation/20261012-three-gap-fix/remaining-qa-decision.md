- 事实：A01 按冻结合同推近真实源画面。采集器将整个 video DOM 的外接矩形当成 overlay，背景墙面越过画布就标为 clipped；该值保留。保护区审计与实际帧是另一类证据，不能直接把 clipped 改成 inside。
- 原合同依据：motion-editorial-v3-design/architecture-and-contracts.md 的源坐标 crop / 输出坐标 overlay 分工，以及 visual-and-audio-spec.md 的 A01 受控真实细节取景。
- 拟议最小适配：分别记录源取景和新增图形裁切；只有当前已批准 shot、实际源资源、真实矩阵和保护证据全部绑定时，才按源取景合同核验。新增图形、产品、字幕、关键 UI 及未批准的人脸/手部裁切仍拒绝。未知或缺证不能降级为通过。
- 所需验证：允许的背景裁切正例；错误源/计划哈希、产品/人脸/手/字幕受损、图形越界、失踪目标、缺证反例；实际短片复核。不得通用忽略 clipped。

## QA-B：动态 GSAP 未被静态 CLI 动画图枚举

- 事实：当前固定 HyperFrames CLI 对外部脚本构建的 GSAP 时间轴返回空 tweens；真实渲染正常，独立浏览器运行树有实际 tween。两类原始结果分别保留，不能把运行树伪装成 CLI 输出。
- 拟议最小适配：在保留原 CLI 证据路线的前提下，为真实 runtime animation-map 制定第二来源合同；要求工具/浏览器、当前工程及输入哈希、真实 DOM 目标、全局起止时间、正反向 seek 和四相位帧对应。来源不同必须可见。
- 所需验证：嵌套 timeline 时间变换、空树、失踪目标、陈旧哈希、错事件窗口、静态假列表均阻断；四相位 preview/render parity 必须用实际成片重验。不得以一份手写 tween 列表过门。

## QA-C：真人非整帧镜头的实际一帧差异

- 事实：动作处实渲染第 410 帧与预览同帧 SSIM 0.914039，而与预览第 409 帧为 0.984093；普通画面对照第 1500 帧同帧为 0.984858。不是统一整片偏移，不能选择最佳偏移冒充通过。
- 关联：A01 媒体片段从 13.49 秒（404.7 帧）启动。具体偏差来自浏览器还是 HF 编译/解码取整仍未证实，不把可见首帧 405 冒充编译器实际记录。

- 新阻塞：固定 HF strict checker 以 tag/src/start/duration 判重，报告唯一 duplicate_media_discovery_risk；它不检查父宿主显隐，但警告仍真实保留。新方案**未渲染**，不能声称错帧已修复；当前可观看真人候选仍是修复前版本。
- 拟议适配：为意图明确的同源多实例媒体时间轴制定证据约束，继续阻断意外重复/遮盖/音频重复；或采用不触发警告的等价实现。不得直接禁用 strict、伪造不同源或降低相似度阈值。获批后允许一次必要的原窗口短片技术重渲染，再检查原错帧位置及全相位，而非拿 DOM 门控测试代替实际成片。
