# 本轮证据边界

- 本轮只验证隔离短片风格，不能替代正式 Director 集成、完整视频验收或真实高光前置验收。
- 新旧对照以相同源窗口、字幕与音频为准；无法从旧成片剥离装饰时，使用原画作为无动效 baseline，旧版仅作历史参考。
- `timeline_projection` 的冻结合同包含精确 hook 审批要求。本轮没有该批准，因此不把普通样片窗口映射冒充已获批的 hook projection，不伪造审批字段。hook 投影的实现测试使用明确标注的合成数据。
- 单元测试、文件哈希、完整解码、响度/真峰值测量只能证明相应的可重复事实。字幕错字、切点听感、品牌质感及是否吸引人仍须分别检查。
- 当前没有已证实的本地音频感知入口；不能把波形、响度或静音检测称为完整听审。输出完整带原声样片，听审保留 `pending_human`，不得填通过。
- 真人窗口开头若采用连续语流中的精确词边界，将记录没有可用前置 padding 的风险；不通过扩展到前一个词内部来伪造安全边界。该接句不代表独立开头。
- HyperFrames 快照关闭自动云描述，使用本地已有版本；不因环境已有凭据而自动调用付费/云模型，不安装新依赖，不发送公开反馈或上传样片。
- 冻结候选及既有批准保持历史字节不变；此次用户授权记录在独立收据中，审美结果初始为 pending。
