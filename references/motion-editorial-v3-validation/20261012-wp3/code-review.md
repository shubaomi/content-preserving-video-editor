Review scope: production projection/config/Director/caption bridge, six A/B components,
instance handoff/editable delivery, exact-hook review and isolated variant boundary.
Reviewers were separate agents from the implementing owners; this is not a user
aesthetic, publication, or real-editor acceptance receipt.

## Findings resolved before final delivery

- Step evidence previously omitted B02 nested frame hashes: all step references now
  checked and limited to the exact semantic instance's frame inventory.
- EDL source path could disagree with current source hash: require one explicit
  authorized source in both baseline and candidate EDLs.
- Component active_end / compiler defaults disagreed: materialize the same finite
  boundary and reject an exit after it. A02 requires an actual current instance target.
- Legacy ID schemas rejected output instances: additive 1.1 schemas, frozen 1.0 unchanged.
- Sample intent could claim opening while rendering a middle window: bind actual
  storyboard/candidate files, EDL-output window and measured duration; purpose limits apply.
- Approved hook could be consumed in an unrelated old project: canonical request target,
  exclusive initialization, read-only same-request recovery and Junction refusal.
- A01/text-free B01 conflicted with source-v3 copy requirements: explicit source_only
  v4 adapter preserves the source copy and old validator; output copy is deterministically
  empty only for those two recipes. Original subtitles are untouched.
- Editorial metadata was mistaken for visible copy: v4 verifies exactly three typed
  linkage fields; actual plan matching remains a separate gate. Reuse the existing
  visible_copy_manifest instead of introducing a competing copy authority.
- Large-video hash memory spike: variant references use streaming sha256_file.

Final independent verdict: approve; no remaining blocking findings in reviewed scope.
Reviewer reruns included Director, variant and original contract regressions.
Actual local browser + GSAP checks covered six recipes with random/reverse seeking;
these synthetic DOM/geometry checks do not prove a real composition is attractive.
