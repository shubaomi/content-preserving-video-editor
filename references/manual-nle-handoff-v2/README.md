# Manual NLE Handoff v2 design freeze

This directory freezes the design for an editor-neutral, Jianying-friendly
manual finishing package. It extends the existing optional `manual_finish`
handoff without changing the default one-shot workflow.

Status: `pending_user_approval`.

This design does not implement a Jianying draft writer, invoke Jianying, render
a full video, or promote any capability maturity. The automatic universal MP4
remains the immutable reference and delivery fallback.
