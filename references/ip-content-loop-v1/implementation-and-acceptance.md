## 测试数据与成功标准

1. **既有中文耳机口播问题**：语义分组夹具需把工艺补语归前句，把“轻轻一放”
   归动作句；词序/词数/时间保持，不以单行测试替代听看质量。
2. **第三方数据报表介绍**：标题与承诺绑定实测 UI；不出现 HongRun 个人自述。
3. **参考视频结构迁移**：相同词重复两次，只能绑定被选中的 word IDs；参考时码
   不能直接进入输出效果时间。无对应证据的参考机制不渲染。
4. **局部微调**：仅改强调色，ASR/EDL 不重跑；工程、caption manifest 与批准的
   实际失效按既有行为执行。若无法局部缓存，明确 fallback 成本，不能伪造命中。
5. **发布数据**：两次同发布快照仍计 1 个独立视频；不同窗口/来源/口径不可比较；
   0 与缺失严格区分；未知评论作者信息不传播到产物。
6. **默认兼容**：enabled=false 时十九阶段、默认 keys/输出及授权门行为与基线相同。
7. **中断恢复**：退出后相同哈希复用；替换同路径同大小文件也失效；共享策略不被写入。
8. **交付**：SRT/ASS/无新增字幕候选与 HyperFrames 可编辑源全部维持；剪映人工
   验收未做就保留 pending，不因新功能 green tests 改为完成。

真实 canary 使用一条授权个人口播和一条授权第三方屏幕演示的 30–60 秒窗口；
复用已有素材/证据，先检测其是否仍有效。新增渲染先依现有样片/外部执行授权判断，
不把设计批准当成无限渲染授权。比较主张清晰、字幕易读、解释帮助、身份合适、
修改可控与愿意发布。自动事实检查和人类审美分别记录。

## 迁移和回滚

新 sidecar 使用自己的 version=1；project schema 14 将 1–13 内存迁移，
默认关闭，不编辑用户 YAML。先独立 validator，再接入现有 stage，不反向更改
先前 approved design。回滚时恢复上一个代码提交，保留原项目、旧状态和所有新
侧层产物供排查；不让旧版本读取 schema 14 冒充 schema 13。使用升级前保存的
项目配置和状态副本，或在新项目目录复现，禁止回退时覆盖用户后续修改。

共享 Profile 永不自动更新。hypit 安装与编辑器工具独立，不参与回滚用户视频。
Hypit 运行时适配器不在这些工作包；它需要单独短片实验和工具所有权设计批准。

## 完成定义

报告代码/合同测试、当前真实 canary、用户门、未验证项四种证据。只暂存本任务
文件，经验证后聚焦提交并非强制推送上游。生成物、私密素材、账号和模型凭据
不入 Git。保持 global junction 指向正式源码，核对两条路径读到同一 SKILL 哈希。
