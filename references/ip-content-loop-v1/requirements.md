# 需求追踪与当前基线

## 事实来源和冲突裁决

顺序：当前用户明确请求及边界 → 已批准设计 → 当前代码/测试 → 本候选 →
研究项目文档/宣传。第三方 README 的生成优先策略不能覆盖内容保留合同。
用户请求恢复原路径、安装 Hypit、参考开源项目完善 Skill、同步全局并提交推送。
此前讨论提供 IP 闭环方向；尚未提供具体受众定位、商业目标或自动化运行时批准。

当前基线 `bcb426dac51a07dd94aaeddef7dea969509c2c70`，项目 schema 13。
现有 `editorial_promise.py` 已接收 audience、viewer_job、single_promise、
proof_event_ids、CTA、tone、prohibited_claims，不能再造第二套权威。
`post_publish_metrics.py` 已校验指标，`feedback_loop.py` 已处理单一发布的
时间序列并输出建议；v1 扩展的是跨视频可比性及到下期内容的可审阅连接。

## 用户收益与范围

收益：减少无效精剪、避免包装夸大、复用已通过素材、让改进来自实际发布观察。
通用 Agent 也能做选题和文案；本项目价值来自真实词/画面/时间轴/发布版本的
持久绑定和可编辑资产，不把提示词、更多动效或 Hypit 安装当独有壁垒。
留存、付费和增长效果均未验证，v1 不承诺这些结果。

## 非目标和不可改变项

不自动改人设、不克隆真人声音或形象、不改写录制原话、不自动重排 EDL、
不默认增加新效果或收费模型、不启动剪映、不读取或写入其 APP 草稿目录、
不自动发布/私信/抓取评论、不升级 production_default。
仍默认一个 Universal MP4，并包含标准可编辑字幕/样式/无新增字幕候选。
日常模式只减少可选实验，不降低字幕、原意、权利、音频、样片与人工门标准。
