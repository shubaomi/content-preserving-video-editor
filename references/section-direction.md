# 全片结构与逐段呈现

适用于保留原片的剪辑、已有成片微调，以及从脚本和授权素材生成新片。下列是导演在现有创意笔记、分镜与审片记录里执行的规则，不新增机器合同、流水线阶段或批准门。

## 先定整片，再定段落，最后定镜头

1. **整片**：给谁看？观众看完应能理解、判断或完成什么？根据真实内容写出段落顺序，每段用一个观众问题命名，不用“转场 A、缩放 B”命名。教程可以从任务的起始状态入手，采访可以顺着一件具体经历，产品总览可以围绕几种使用场景。不是每条片都需要钩子、功能列表或行动号召。
2. **段落**：为每一段（含刻意保留的连续原画）在现有创意笔记或 `frame.md` 留一行：**范围／观众问题 → 看完能明白什么 → 真实依据 → 主画面及选择理由 → 旁白或原声在哪个词让画面接手 → 怎样接到下一段**。有 EDL 就沿用其顺序、时间及原话；新片尚未定时时先用段名与脚本句，不编时间码。简单短片可只写一行。缺素材时注明能证明到哪里，不让渲染器临场编造。
3. **镜头**：先通读相邻段，确定观众的视线从哪里来到哪里去，再决定需不需要鼠标、推拉、转场或音效。若稳镜或直切已经讲清，就选它。把段落选择交给既有分镜落实；不改已批准的语义、字幕、EDL 或冻结的 JSON 字段。局部返修保留未受影响的结构、原声及授权。

| 观众这时需要什么 | 通常更清楚的主画面 | 什么时候换手 |
|---|---|---|
| 先理解一个概念、关系或差别 | 一句话配图、简图、同尺度真实截图对照；让人读完 | 一旦声称“如何做到”，切到操作证据；示意图不是实测 |
| 看清某一步怎样改变结果 | 连续实录保留起始状态 → 操作 → 可见结果；必要时才跟随鼠标推近，结果出现后稳住 | 下一句讲含义、适用人群或对比时，可留住结果、并排比较或切走，不必再游览界面 |
| 判断人物的态度、感受或实物的反应 | 保留表情、停顿、接触动作和现场声；确有帮助再插入一张授权原图或局部细节 | 引用或细节说完回到人或物，不用反复切走填满停顿 |

这不是形式配额。同一个产品的总览与排障教程可以完全不同。同一机位也可以讲完整个回答；只在观众任务变化且另一种画面有实际收益时换。不用换颜色、重复推拉或添加过场冒充表达方式变化。

## 验收：看连续段落，而不只看漂亮单帧

- **制作前**用分镜连读一次：每个必讲问题有没有归属、依据和合适的主画面？把相邻两段的画面对调，若照样能套用，检查是否只是装饰。能用一张图讲清的关系却安排连续找菜单，或声称操作成功却只有静帧，先回改分镜。
- **导出后**按正常速度跨段播放，对照整片提纲，在现有审片记录写下**段落／实际时间窗／实际看见的证据或变化／保留或返修理由**。最容易误判的切点同时看片前、动作和结果；单帧与剪辑工程不能证明动作或观看节奏。核对说明能读完、操作结果看得到、情绪没被打断，切换后仍知道在看谁或什么。样片没覆盖的段标为未验。
- **反查两种单调**：全片都是图文，是否有该展示的行动没被证明？全片都在追鼠标或套同一动效，是否有需要读、比较或听人说完的段落被打断？任一处影响理解或误导，记下具体窗口及替代方式，修正后重看该段与前后衔接。长镜头、连续教程或全程图文若确实最合适，可据实通过；既不以“用了几种”判优，也不以“全片只有一种”自动判错。
- 这是内容验收，不是解码、特效计数或自动审美评分。技术通过不等于导演审看通过，也不替代用户对风格和发布的决定。
